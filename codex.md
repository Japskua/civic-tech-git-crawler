# Civic Tech Verification

Criterion used: a project counts as civic tech when the repository itself serves a public-interest civic outcome: government services, democracy/elections, public accountability, public data, community resilience, public health/safety, access to rights/benefits, digital rights, or civic participation. Generic libraries, internal templates, design systems, and infrastructure modules are marked No unless their repository purpose is directly civic-facing.
